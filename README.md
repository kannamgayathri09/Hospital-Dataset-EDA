🏥 Hospital Data Analysis using Python

📌 Project Overview

The Hospital Data Analysis project focuses on exploring and analyzing patient and hospital data to identify patterns in treatment costs,patient demographics, 
diagnoses, hospital revenue, and payment methods.This project uses Exploratory Data Analysis (EDA) techniques to uncover healthcare insights using Python.

📊 Dataset Information

•	Source: Hospital Dataset
•	Rows: 1500 Patient Records
•	Columns: Multiple Healthcare Features

Key Features
•	Patient_ID – Unique patient identifier
•	Gender – Patient gender
•	City – Patient city
•	Department – Hospital department
•	Diagnosis – Medical condition
•	Treatment_Cost – Cost of treatment
•	Length_of_Stay – Hospital stay duration
•	Payment_Mode – Payment method
•	Revenue – Revenue generated

🎯 Project Objectives

•	Understand the structure of the hospital dataset
•	Handle missing and inconsistent data
•	Perform Exploratory Data Analysis (EDA)
•	Visualize healthcare and financial trends
•	Generate actionable insights

🛠 Technologies & Libraries Used

•	Python
•	Pandas
•	NumPy
•	Matplotlib
•	Seaborn

🔍 Steps Performed

1.	Data loading and inspection
2.	Data cleaning and preprocessing
3.	Handling missing values
4.	Outlier detection
5.	Exploratory Data Analysis (EDA)
6.	Data visualization
7.	Insight generation

📈 Exploratory Data Analysis

The following analyses were performed:

•	Patient distribution by gender
•	Department-wise analysis
•	Diagnosis-wise treatment cost analysis
•	Revenue analysis
•	Length of stay analysis
•	Payment mode distribution
•	City-wise patient distribution

🧠 Key Insights

•	Heart Disease treatments recorded the highest average treatment cost.
•	Neurology department showed the highest treatment expenses.
•	Male patients represented a larger share of admissions.
•	Hyderabad contributed the highest number of patients.
•	UPI was the most preferred payment method.
•	Patients with Infection and Diabetes had longer hospital stays.

📊 Visualizations Used

•	Count plots
•	Bar charts
•	Pie charts

✅ Conclusion
Exploratory Data Analysis revealed that treatment cost, diagnosis, department performance, and patient demographics significantly impact hospital operations and 
revenue. The project demonstrates how data analytics can support better healthcare decision-making.
